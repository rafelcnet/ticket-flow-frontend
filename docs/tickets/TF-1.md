# TF-1 - Configuracion base del proyecto

**Tipo:** Historia
**Prioridad:** Alta
**Epica:** TicketFLow FrontEnd

### DESCRIPCION
Como equipo, necesitamos tener la base técnica del proyecto lista — estructura, dependencias y navegación inicial — para poder empezar a construir las pantallas de TicketFlow sobre unos cimientos consistentes.

### CRITERIOS DE ACEPTACION
- [ ] El proyecto puede ejecutarse localmente con un solo comando
- [ ] Existe una versión inicial, aunque vacía, de cada pantalla principal: login, inicio, compra y mis reservas
- [ ] La aplicación sabe contra qué entorno debe comunicarse para obtener datos

### DEFINICION DE TERMINADO (DOD)
- [ ] Todos los criterios de aceptación se cumplen
- [ ] No hay errores visibles en la consola del navegador durante el flujo normal de uso
- [ ] El código fue revisado y aprobado por el equipo antes de integrarse
- [ ] Verificado manualmente en el entorno de desarrollo
