### DESCRIPCION
Como usuario, quiero pagar mi boleto y recibir una confirmación clara, para tener la certeza de que mi compra se realizó correctamente.

### CRITERIOS DE ACEPTACION
- [ ] Puedo elegir entre pagar con tarjeta o con PayPal
- [ ] No puedo enviar el pago si mis datos de pago están incompletos
- [ ] Mientras se procesa el pago, veo que la aplicación está trabajando en ello
- [ ] Si el pago es aprobado, veo una confirmación con los detalles de mi compra
- [ ] Si el pago es rechazado, veo el motivo y puedo intentar de nuevo sin perder mis datos
- [ ] Si reintento el pago después de un rechazo, no se me cobra dos veces por el mismo boleto

### DEFINICION DE TERMINADO (DOD)
- [ ] Todos los criterios de aceptación se cumplen
- [ ] No hay errores visibles en la consola del navegador durante el flujo normal de uso
- [ ] El código fue revisado y aprobado por el equipo antes de integrarse
- [ ] Verificado manualmente en el entorno de desarrollo
